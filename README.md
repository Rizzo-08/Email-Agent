# Email Agent 📧

Un agente AI che genera email professionali in italiano.

## Come funziona
Descrivi cosa vuoi comunicare e l'agente genera un'email professionale completa.

## Tecnologie
- Node.js
- Express
- Groq API (LLaMA 3.3 70B)

## Setup
1. Clona la repo
2. Crea un file .env con la tua GROQ_API_KEY
3. npm install
4. node server.js
